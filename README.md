# Msgly

**Schedule and automate your WhatsApp messages — all from one app.**

Msgly is a desktop app that lets you send bulk messages, schedule campaigns, and manage contact lists directly through WhatsApp — no third-party API required.

## Features

- **Bulk messaging** — Send to hundreds or thousands of contacts at once
- **Message scheduling** — Set a date and time, Msgly sends it automatically
- **Recurring messages** — Daily, weekly, monthly — any schedule you need
- **Contact list manager** — Build and organise custom contact groups
- **Unlimited contacts** — No caps, no tiers
- **Unlimited schedules** — Run as many campaigns as you want simultaneously

## macOS Installation

Because Msgly is not notarized, macOS may block it on first launch:

1. Download the DMG for your chip
2. Open the DMG and drag **Msgly** to Applications
3. In Finder, **right-click Msgly → Open**
4. Click **Open** in the warning dialog

This is only needed once.
